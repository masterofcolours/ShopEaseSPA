# Vanilla JS E-Commerce SPA

A high-performance, modular e-commerce Single Page Application built entirely from scratch using native Web Components and Vanilla JavaScript without external framework dependencies.

## Features

- Custom client-side router utilizing the History API and Regular Expression dynamic path matching.
- Reactive Pub/Sub state management store for seamless UI synchronization across components.
- Component-based architecture encapsulated within Shadow DOM.
- Dynamic product detail views, user authentication forms, and checkout workflow.
- Absolute pathing and robust state handling to prevent 404 errors during client-side navigation.

## Technologies Used

- Vanilla JavaScript (ES6+)
- Web Components & Shadow DOM
- HTML5 & CSS3

## Getting Started

To run this project locally, clone the repository and serve it using any local static file server (such as Live Server in VS Code):

1. Clone the repository.
2. Open the project folder in your code editor.
3. Run the project using a local development server to support ES modules and JSON fetching.
